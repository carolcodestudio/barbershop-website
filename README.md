# 💈 Barbearia Imperial Website


Projeto de um site moderno para uma barbearia, desenvolvido para demonstrar criação de páginas profissionais, responsivas e focadas na experiência do usuário.


## 🚀 Sobre o projeto

A Barbearia Imperial é um website fictício criado pela CarolCode Studio.

O objetivo do projeto foi desenvolver uma página comercial com:

- Apresentação da empresa
- Serviços
- Galeria de imagens
- Avaliações de clientes
- Botão de contato via WhatsApp


## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages


## 🎨 Funcionalidades

✅ Layout responsivo  
✅ Menu de navegação  
✅ Seção de serviços  
✅ Cards com animação  
✅ Galeria de imagens  
✅ Botão de WhatsApp  
✅ Favicon personalizado
